# Actual LLM experiment and numerical-reconstruction archive

Version: v1.1.0-llm-v124-v125. Experiment: 8–9 September 2026 UTC. Archive: 11 September 2026.

This release supplies the missing original-prompt and accepted-response materials
for the September FPV manuscript, rather than a replacement illustrative template.
It adds four exact SDK protocols, 4,701 primary and 471 comparison final answers,
18 rejected attempts, a complete internal waterbody-group map, frozen inference
source, real score-to-weight example and offline reconstruction scripts.

The underlying v124 scores and v125 water results are unchanged. Root-level v118
data, terminology and authorship metadata remain historical; this release's materials
are explicitly versioned separately. No model retrieval tools or policy-text searches
are retroactively added. No model internal reasoning streams or restricted source
datasets are published. Temperature and seed remain unspecified where the actual SDK
did not set them. Full physical reruns still require authorized upstream data.

Validation and reconstruction results accompany the GitHub release as separate
assets so generated reports do not alter the frozen source checksums. DOI archival
is a subsequent step; this version does not claim an issued DOI.
